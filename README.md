# RentReady AI

An AI rental application copilot that prepares complete, verified applications so renters can apply with confidence.

## Tech stack

React, TypeScript, Vite, Vercel AI SDK, Supabase Edge Functions (`chat`, `pipeline`, `autopilot`, `run-agent`), i18next

## Run locally

```sh
npm install
npm run dev
```

See `setup.mjs` and `supabase/migrations/` for backend setup.
